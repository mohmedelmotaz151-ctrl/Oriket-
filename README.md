# أوريكيت للصيانة
نسخة ويب كاملة مبدئية لإدارة العملاء وطلبات الصيانة والفنيين وقطع الغيار والفواتير باستخدام Firebase.

## الإعداد
1. أنشئ مشروعًا في Firebase.
2. فعّل Authentication > Email/Password.
3. أنشئ مستخدم مدير من Authentication > Users.
4. أنشئ Firestore Database.
5. أنشئ Web App وانسخ firebaseConfig إلى app.js.
6. ارفع الملفات إلى GitHub.
7. فعّل GitHub Pages من Settings > Pages > Deploy from branch > main > root.

## ملاحظة
قبل الاستخدام الفعلي يجب تشديد Firestore Security Rules وإضافة صلاحيات للأدوار.
