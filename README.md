# أوريكيت | نظام إدارة زيارات الدفاع المدني

نسخة احترافية Mobile-first تعمل مباشرة من GitHub Pages أو Vercel، ومصممة لإدارة منشآت وزيارات وفحوصات أنظمة السلامة.

## المزايا الحالية
- لوحة تحكم وإحصائيات.
- إدارة المنشآت والعملاء.
- تسجيل زيارات الدفاع المدني.
- قوائم فحص لأنظمة الإنذار والرش والمضخات والطفايات ومخارج الطوارئ.
- خريطة تفاعلية للمواقع عبر OpenStreetMap.
- تقارير زيارة قابلة للطباعة والحفظ PDF.
- تصدير سجل الزيارات CSV.
- PWA قابلة للتثبيت على Android.
- تخزين محلي مؤقت عبر localStorage، بدون وضع أي مفاتيح سرية في GitHub.

## التشغيل
افتح الموقع بعد النشر. النسخة الحالية تستخدم تسجيل دخول تجريبي محلي:
- البريد: admin@oriket.site
- كلمة المرور: 123456

> هذا الدخول تجريبي للواجهة فقط، وليس نظام صلاحيات إنتاجياً.

## المرحلة الإنتاجية المقترحة
لتحويل النسخة إلى نظام متعدد المستخدمين: اربطها بـ Supabase أو Firebase لإضافة حسابات المندوبين، قاعدة بيانات مركزية، رفع الصور، صلاحيات المدير/المندوب، وسجل زيارات متزامن بين الأجهزة. لا تضع Service Role Key أو أي مفتاح سري داخل المستودع.

## النشر
GitHub Pages: Settings → Pages → Deploy from branch → main → /root.
